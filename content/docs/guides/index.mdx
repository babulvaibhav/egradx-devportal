description: One guide per capability of the SDK — what it is, how it works, how to use it in Java, Node and Python, what it guarantees, and how OIM uses it.

Each guide follows the same order: **what it is and why**, **how it works**, **the code** (cut from the example applications, which are what [the Initializr](/start) generates), **what it answers** (recorded from those applications), **configuration**, **guarantees and limits**, and **in OIM**. The marks under each title say how far each language has it; [the parity page](/docs/reference/parity) has them all.
