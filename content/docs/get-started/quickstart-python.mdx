You need Python 3.12 or later, [uv](https://docs.astral.sh/uv/), a PostgreSQL database ([local environment](/docs/get-started/local-environment)) and the SDK's wheels in a folder ([access to the packages](/docs/get-started/access)).

The code on this page is the portal's Python example application, `examples/python` — a small *notes* application built on the published wheels and run by the portal's build checks. You can copy it whole.

  [The Initializr](/start?lang=python) makes this project, and more, as a zip: choose what you need, and it builds and passes its tests as generated. This page builds it by hand, so you see each part.
</Callout>

### Wire the SDK

The SDK runs its SQL through **your** SQLAlchemy engine, so its writes join your transactions. Its tables are migrated first (so yours can reference them), then yours, with the SDK's migration runner. `seed(...)`, `note_routes(...)` and the `on_organization_created` listener are the application's own — they come in [your first endpoint](/docs/get-started/first-endpoint).

<RepoSnippet file="apps/egradx-devportal/examples/python/application.py" region="main" title="application.py" />

The end of `main.py` starts uvicorn on a selector event loop: psycopg's async mode needs one, and Windows does not use it by default.

<RepoSnippet file="apps/egradx-devportal/examples/python/main.py" region="run" title="main.py (end)" />

</Step>
<Step>

### Run it

```sh
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/notes EGRADX_KEY_PASSPHRASE=change-it uv run python main.py
```

On first start the SDK creates its tables, generates the signing keys in `./keys`, and seeds the platform organization with its administrator.

</Step>
<Step>

### Sign in

```sh
curl -s -X POST http://localhost:8080/egradx/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"platform-admin","password":"change-me-platform-admin"}'
```

The answer carries an `accessToken` and a `refreshToken`. Call the SDK with the access token:

```sh
curl -s http://localhost:8080/egradx/auth/me -H "Authorization: Bearer $ACCESS_TOKEN"
```

<Callout title="The seeded administrator">
  `platform-admin` / `change-me-platform-admin` unless you pass `AuthOptions(platform=PlatformSettings(admin_password=...))` before the first start.
</Callout>

</Step>
