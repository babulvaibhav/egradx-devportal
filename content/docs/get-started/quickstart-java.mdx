You need Java 21, Maven, a PostgreSQL database ([local environment](/docs/get-started/local-environment)) and [access to the packages](/docs/get-started/access).

The code on this page is the portal's Java example application, `examples/java` — a small *notes* application built on the published packages and run by the portal's build checks. You can copy it whole.

### Run it

A plain Spring Boot main class is all the wiring there is: every library configures itself.

<RepoSnippet file="apps/egradx-devportal/examples/java/src/main/java/com/acme/notes/NotesApplication.java" region="main" title="NotesApplication.java" />

```sh
EGRADX_KEY_PASSPHRASE=change-it mvn spring-boot:run
```

On first start the SDK creates its tables, generates the signing keys in `./keys`, and seeds the platform organization with its administrator.

</Step>
<Step>

### Sign in

```sh
curl -s -X POST http://localhost:8080/egradx/auth/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"platform-admin","password":"change-me-platform-admin"}'
```

The answer carries an `accessToken` and a `refreshToken`. Call the SDK with the access token:

```sh
curl -s http://localhost:8080/egradx/auth/me -H "Authorization: Bearer $ACCESS_TOKEN"
```

<Callout title="The seeded administrator">
  `platform-admin` / `change-me-platform-admin` unless you set `egradx.auth.platform.admin-password` before the first start.
</Callout>

</Step>
