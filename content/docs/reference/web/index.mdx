The browser packages: the client, the React hooks and the Next.js backend-for-frontend. The copy-in screens are source you own, served at `/r/<item>.json`. Each page starts with the package's own overview, then every export.

| Package | What it is |
|---|---|
| [`@babulvaibhav/egradx-client`](/docs/reference/web/egradx-client) | Framework-agnostic browser and Node client for applications built on the EGRADX SDK: typed API, sessions with token refresh, errors, and the notification inbox. |
| [`@babulvaibhav/egradx-next`](/docs/reference/web/egradx-next) | A backend-for-frontend for Next.js in front of an EGRADX API: the tokens stay in HttpOnly cookies on the server, the browser's @babulvaibhav/egradx-client runs with tokens: 'server', and server code gets the session and a signed-in fetch. |
| [`@babulvaibhav/egradx-react`](/docs/reference/web/egradx-react) | React bindings for @babulvaibhav/egradx-client: provider, session and auth hooks, the &lt;Can&gt; gate, the notification inbox, and hooks for the audit trail, notification administration and a person's own settings. Headless: no UI kit, router or query library. |
