## Where to start

| Package | What is in it |
|---|---|
| `com.egradx.auth` | `EgradxRoleService`, `EgradxOrganizationProvisioningService`, `EgradxUserService` |
| `com.egradx.auth.security` | the caller: `EgradxTenantContextAccessor`, `EgradxAuthenticatedPrincipal` |
| `com.egradx.audit`, `com.egradx.core.audit` | `EgradxAuditor`; `EgradxAuditEvent` and its builder |
| `com.egradx.notification.messenger` | `EgradxMessenger`, `EgradxMessageRequest` |
| `com.egradx.notification.template`, `.inbox`, `.spi` | `EgradxNotificationType`; `EgradxInAppMessage`; `EgradxNotificationChannel` for channels of your own |
| `com.egradx.events` | `EgradxEventPublisher`, `EgradxEventHandler`, `EgradxEvent` |
| `com.egradx.core.exception` | the exceptions every endpoint answers with the error envelope |
| `com.egradx.observability` | request ids, `EgradxMetrics`, log shipping |

Most applications depend on `egradx-sdk` alone, which brings the others, plus `egradx-platform-events` when they publish events. Configuration keys are listed in [configuration](/docs/reference/configuration).
