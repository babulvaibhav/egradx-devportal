Java is the reference implementation; Node and Python follow it, checked by the same contracts and conformance tests, and the web packages run against all three. Hover a mark for its caveat; the notes say the same under each row.

| Mark | Means |
|---|---|
| ✓ | available, and checked against an application in that language |
| ◐ | partial: usable, with the caveat noted |
| ○ | planned: not built yet — don't build your own; write a small interface you can swap later |
| ✕ | not available |
| – | not applicable |
