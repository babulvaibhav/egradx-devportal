The Node SDK, package by package. Most applications need only @babulvaibhav/egradx-sdk, which re-exports the others it wires, and @babulvaibhav/egradx-events when they publish events. Each page starts with the package's own overview, then every export.

| Package | What it is |
|---|---|
| [`@babulvaibhav/egradx-audit`](/docs/reference/node/egradx-audit) | EGRADX server SDK for Node: the audit trail. Append-only records stored with the change they describe, filters, history, CSV export, retention. The counterpart of the Java egradx-audit. |
| [`@babulvaibhav/egradx-audit-auth`](/docs/reference/node/egradx-audit-auth) | EGRADX server SDK for Node: connects egradx-audit to egradx-auth (who acted, names on records, the audit authorities). The counterpart of the Java egradx-audit-auth. |
| [`@babulvaibhav/egradx-auth`](/docs/reference/node/egradx-auth) | EGRADX server SDK for Node: authentication and identity. Sign-in, sessions and tokens, organizations, roles and permissions, invitations, password reset, profiles. The counterpart of the Java egradx-auth. |
| [`@babulvaibhav/egradx-core`](/docs/reference/node/egradx-core) | EGRADX server SDK for Node: exceptions with the contract's error codes, the error envelope, shared enums, request ids and the per-request context. |
| [`@babulvaibhav/egradx-events`](/docs/reference/node/egradx-events) | EGRADX server SDK for Node: events between services. CloudEvents through a transactional outbox, a deduplicating inbox, in-process by default, RabbitMQ or Kafka by configuration; log shipping over them. The counterpart of the Java egradx-platform-events. |
| [`@babulvaibhav/egradx-express`](/docs/reference/node/egradx-express) | EGRADX server SDK for Express: request ids and context, authentication from EGRADX access tokens, and the error envelope for every failure. |
| [`@babulvaibhav/egradx-file-storage`](/docs/reference/node/egradx-file-storage) | EGRADX server SDK for Node: files an application's users upload. Organization-scoped files with built-in permissions, application access checks for attached records, profile photos, streamed downloads with Range, on local disk or any S3-compatible store. The counterpart of the Java egradx-file-storage. |
| [`@babulvaibhav/egradx-migrations`](/docs/reference/node/egradx-migrations) | EGRADX server SDK for Node: applies a capability's contracts/db migrations to PostgreSQL in Flyway-compatible history tables, so Java and Node applications can share a database. |
| [`@babulvaibhav/egradx-notification`](/docs/reference/node/egradx-notification) | EGRADX server SDK for Node: notifications. The in-app inbox with its live stream, outbound messages through email, Slack, SMS, WhatsApp and webhooks, templates, and channel settings. The counterpart of the Java egradx-notification. |
| [`@babulvaibhav/egradx-notification-auth`](/docs/reference/node/egradx-notification-auth) | EGRADX server SDK for Node: connects egradx-notification to egradx-auth (recipients, audiences, opt-outs, inbox and admin callers, account messages). The counterpart of the Java egradx-notification-auth. |
| [`@babulvaibhav/egradx-observability`](/docs/reference/node/egradx-observability) | EGRADX server SDK for Node: metrics, traces and request ids for every egradx library and application, through the OpenTelemetry API; the counterpart of the Java egradx-observability. |
| [`@babulvaibhav/egradx-redis`](/docs/reference/node/egradx-redis) | EGRADX server SDK for Node: several instances of an application acting as one, through Redis. Sign-in attempts counted together, role changes evicted from every instance's cache, in-app notifications pushed live on every instance; fail open when Redis is down. The counterpart of the Java egradx-redis. |
| [`@babulvaibhav/egradx-sdk`](/docs/reference/node/egradx-sdk) | EGRADX server SDK for Node: the one dependency an application needs to start. Sign-in and identity (@babulvaibhav/egradx-auth), the audit trail (@babulvaibhav/egradx-audit) and notifications (@babulvaibhav/egradx-notification), connected to each other and set up with one call. The counterpart of the Java egradx-sdk. |
| [`@babulvaibhav/egradx-security`](/docs/reference/node/egradx-security) | EGRADX server SDK for Node: verifies EGRADX access tokens into the caller's context, and obtains service-to-service tokens. |
| [`@babulvaibhav/egradx-tls-provider`](/docs/reference/node/egradx-tls-provider) | EGRADX server SDK for Node: the RSA signing and encryption keys, their self-signed certificates and JWK set, kept in a keystore directory as the Java egradx-tls-provider keeps them. |
