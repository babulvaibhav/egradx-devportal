Every page here is made from the SDK itself: the HTTP and data pages from its **contracts** (the OpenAPI, JSON Schema, AsyncAPI and SQL every language implements), the permissions and audit actions from what the example applications answer, and the language pages from the libraries' own source. When the SDK changes, the next build changes them.
