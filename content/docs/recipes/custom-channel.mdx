## What `send` returns

| Result | The SDK |
|---|---|
| `sent()` | marks the delivery `SENT` |
| `retryable(reason)` | tries again later: 30 seconds, doubling up to an hour, eight attempts |
| `permanent(reason)` | marks it `DEAD` at once, with the reason, in the delivery log |

Return a result rather than throwing; anything thrown counts as retryable.

## Rules for a channel

- **Bound every call** with a timeout. A hung call holds a dispatcher slot.
- **Expect a delivery twice.** The dispatcher is at-least-once: if an instance dies mid-send, the delivery is sent again. Pass `deliveryId` on as an idempotency key, as above.
- **Check addresses in `validateAddress`.** A bad address is then refused when the message is sent, not discovered later.
- **Templates:** a channel named `chat` uses `chat.body.txt` (and `chat.subject.txt`) in each type's template folder.
