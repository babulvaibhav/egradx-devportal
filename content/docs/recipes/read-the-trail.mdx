- **Always name the organization.** The search doesn't check who is asking: that is your code's job.
- **A page at a time,** newest first. Pass the page's cursor to get the next one.
- **Filters:** the same as the HTTP API. You can filter on the action or an action prefix, the category, the outcome, the actor, the entity, a changed field, a request or trace id, a time range, and text.

## Over HTTP

| Endpoint | Gives |
|---|---|
| `GET /egradx/audit/events` | a page of the caller's organization's records, with every filter |
| `GET /egradx/audit/timeline?entityType=&entityId=` | one thing's history |
| `GET /egradx/audit/events/{id}` | one record |

All need `egradx.audit.read`. In React, `useAuditLog`, `useAuditTimeline` and `useAuditRecord` wrap them, and the copy-in `audit-log` screen uses those.
