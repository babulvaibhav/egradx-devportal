---
title: Record audit events from a library
description: A library of your own records audit events without depending on the audit package — the application that uses it records them.
---

A shared library (billing, reporting) should not pull in the SDK's audit package and its database. It depends only on the core package, and publishes an audit event. The application's auditor records it, with the same transaction, redaction and rules as its own records.

- `EgradxAuditEvent` and its builder are in the **core** package (`com.egradx.core.audit`, `@babulvaibhav/egradx-core`, `egradx.core`). A library needs nothing more.
- In an application without the audit package, publishing does nothing.
- Name the actions under the library's own category (`reports.report.generated`), and describe them in the application's catalog so the audit screen shows them.
